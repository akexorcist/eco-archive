# PvP Skill Changes

Source page: [pvp-skill-changes.html](pvp-skill-changes.html)

How some skills work differently when you fight other players.

These changes apply in [Arena PvP](arena-pvp.md), the [Champion Battle](champion-battle.md) and [Knight Training](knight-training.md).
